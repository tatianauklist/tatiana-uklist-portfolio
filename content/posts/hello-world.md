Welcome to the blog. This site is built with Next.js, writes posts in plain Markdown, and deploys
to Azure Static Web Apps.

## What's here

- A **portfolio** with a project showcase
- A **blog** — posts live as Markdown files in `content/posts/`, complete with frontmatter for
  title, date, category, and description

To add a new post, drop a `.md` file into `content/posts/` with the same frontmatter shape as this
one. Set `draft: true` to keep a post out of the published list while you're still writing it.
